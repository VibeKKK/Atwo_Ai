# 1 写 lib/par_num.mjs

写一个 Node ESM 数字格式化工具模块，落在 lib/par_num.mjs。

必须导出三个函数，签名固定，不许改名：

- formatBytes(n) 把字节数变成人能读的字符串，如 1536 → "1.5 KB"，1024 → "1.0 KB"，0 → "0 B"
- formatDuration(ms) 把毫秒变成人能读的字符串，如 90000 → "1分30秒"，3500 → "3.5秒"，600 → "600毫秒"
- formatPercent(x, digits) 把 0~1 的小数变成百分比字符串，digits 是小数位，如 (0.856, 1) → "85.6%"

边界必须处理，并且注释里写清你怎么处理的：
- 负数
- 0
- 超出安全整数
- 小数位为 0
- 非数字输入（NaN / null / 字符串）

硬要求：
1. 120 到 180 行之间
2. 每个导出函数都要有 JSDoc（参数、返回、举一个例子）
3. 只用 Node 内置能力，不许引第三方包
4. 不许写 TODO 或省略号代替实现，必须写完
5. 只输出代码，不要解释

落盘：lib/par_num.mjs
