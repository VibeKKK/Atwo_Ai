## D1 负数

现象：1 个用例上分成 2 种行为（负数 -1024）。

- A（keep 这样写）：保留负号（例：负数 -1024 → -1 KB）

- B（clamp 这样写）：夹成 0（例：负数 -1024 → 0 B）

推荐：A 保留负号（例：负数 -1024 → -1 KB）（带符号保留了方向；抹平的一方让「欠了」和「没有」看起来一样。）

代价：选 B（夹成 0）的代价：真实值被抹成 0，下游分不清「确实是 0」和「算不出来」。
