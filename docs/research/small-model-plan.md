# atwo 特色小模型：放哪、多久、多少钱（2026-11-18 决定稿）

## 结论先行

接口补足层继续写确定性代码；只有「判定」与「抽取」两处值得上模型，且先分类器、后 LoRA、绝不从零预训练。

## 三条路的成本

| 路线 | 是什么 | 工程 | 机器时间 | 磁盘/显存 | 钱 |
|---|---|---|---|---|---|
| A. 分类器 | LightGBM / 逻辑回归判通道状态 | 2–3 天出 v0 | 训练 1–5 分钟 CPU；推理 <1ms | <10MB，不用 GPU | 0 |
| B. LoRA 微调 1.5B | Qwen2.5-1.5B 级，畸形输出 → 合法文件块 | 7–10 天（其中 5 天造数据与验收） | 训练 1–3 小时（QLoRA，8G 够）；推理 1–3 秒/次 | 基座 Q4 ≈1GB + adapter 20–50MB | 0 |
| C. 从零预训练 | 自训语言模型 | 数月 | 5070 单卡几个月，数据 TB 级 | 不适用 | 不做 |

时间分布：训练只占 3 小时，造数据与验收占 80%。当前瓶颈是配对的畸形样本只有几十条（今天 6 次假失败那一批），分类器 1k 行够，LoRA 需 2k–5k 条配对，得用现有 4 条通道批量合成 + 规则校验过滤。

## 四个值得放模型的位置（按 省时 ÷ 风险 ÷ 训练成本 排序）

1. 通道状态判定器：该路前 200 字符 + 已耗时/预期 + 模型名 → thinking / stalled / dead / wrapped-json / quota-empty / done。接进 `lib/outcome.mjs` 的 `judgeLaneDeadline`，`TTFB_BY_AGENT` 降为兜底。
2. 产物抽取兜底：畸形输出 → `[{target, content}]`。接进 `lib/land.mjs`，仅在 `splitByFileMarker` 返回空时调用，输出必过 `node --check` 与路径白名单。
3. PRD 压缩器：长 PRD + 本片单元清单 → 只含这片该看的 500 字。接进 `lib/split.mjs` 的 `chunkTask`。价值最大（上下文爆窗那次 27MB 会话直接 INVALID_REQUEST，整轮白跑），但要等 1、2 把样本管道打通。
4. 切分质检（不是切分生成）：一组文件 + 任务 → 「是否强耦合」二分类。接进 `lib/split.mjs` 的 `checkSplit` 当软判据。

## 明确不放的三个位置

- 验收判决：信任根必须确定性（`node --check`、字节数、sha256、引文行号）。模型一进来，「可信交付」这个唯一护城河就没了。
- 生成代码：8G 显存训出来的写码能力打不过免费额度的 GLM-5.3-Flash，纯浪费。
- 菜单名归一：编辑距离 + 别名表就够，`Hy3`/`hy3`/`Hy-3` 是字符串问题不是语义问题。

## 三周节奏

| 周 | 做什么 | 产出 |
|---|---|---|
| 第 1 周 | 补三个日志字段 → 导出脚本 → 特征 → 分类器 v0 → 影子模式 | 能说出「我会怎么判」，不瞎砍；误杀率有数字 |
| 第 2 周 | 抽取器规则基线 + 收失败样本 → 判断 LoRA 到底需不需要 | 大概率结论是「规则 + 模糊匹配够用，LoRA 暂不上」 |
| 第 3 周 | 若第 2 周确实攒到 2k 配对，再上 QLoRA | adapter 接进 `lib/land.mjs` 兜底 |

## 战略理由（唯一能永久拥有的部分）

atwo 现在的命门是额度与界面都是别人的：条款一变、GUI 改一次版、风控一来，产能归零。判定与修复放进本地、零配额、可复现，是这套系统里唯一不依赖他人的资产。这也是「底层永远为我所有」唯一能兑现的位置——不是权重，是判定权。
