## 一、形式化

通道 c∈{codebuddy,trae,workbuddy,doubao,deepseek}，任务 t，观测量 X_{0:s}={TTFB, 字节速率, token 速率, 心跳间隔, 错误文本}，真实状态 θ_s∈{思考中,已死,已完成}，决策 a∈{继续等,判死换路}。损失矩阵以秒为单位（依据：实测一轮修复 85s，白等按墙钟计 1s=1）：L(等,思考中)=0；L(等,已完成)=w·Δ（完成本可立即检出，多等纯浪费）；L(等,已死)=w·Δ（白等）；L(杀,思考中)=F=85（触发一轮修复，尾部情形 420~480）；L(杀,已死)=0（正确）。总风险按决策点累加：R=E[Σ_k L(a_k, θ_{s_k})]。今天实测 2 误杀+2 漏判 → 手调阈值日损失约 2×85+2×50≈270s。

## 二、数学论证

(1) 最优停止：固定时刻阈值丢弃了此前全部证据（2s 已出 token 与 2s 静默的后验完全不同），故非贝叶斯最优。正确形式：记 p_s=P(已死|X_{0:s})，当 p_s > F/(F+w·Δ) 时判死占优；取 Δ=10s、F=85 得阈值 ≈85/95≈0.89，即 89% 确信已死才杀——比拍脑袋的 45s/15s 更原则化。序贯等价形式为 SPRT：对数似然比 Λ_s 越上界 A=ln((1−β)/α) 判死（α=误杀率），越下界 B=ln(β/(1−α)) 判活；Wald 近似 E[s|H]≈((1−β)A+βB)/E[每秒Δloglik]，且 Wald–Wolfowitz 定理保证给定 α,β 下 SPRT 期望停时最短，固定阈值无此保证。(2) 样本复杂度：Hoeffding n ≥ ln(2/δ)/(2ε²)，ε=0.02、δ=0.05 → n ≥ ln(40)/0.0008 ≈ 4611 条标注样本 per 二元判定；5 通道×3 状态朴素展开 15 格 ×4611≈6.9 万，不可行。缓解：共享特征+池化建模留全局一份 4611，通道差异交给 Platt 校准层（只拟合 2 参数，每通道约 200 条）；稀有状态「已死」放宽到 ε=0.05 → n ≥ ln(40)/0.005 ≈ 738 条/通道，可达。(3) 删失偏差：log.jsonl 只记跑完的 run，被掐断样本是右删失观测 T∧C。只用完成样本会低估 P(完成时长>s) 尾部 → 阈值显得更可靠 → 偏乐观，表现为漏判；更糟的是「被杀=已死」这个标签是决策自身的循环论证，会把旧阈值偏差学进新分类器。纠正：Kaplan–Meier Ŝ(s)=Π_{t_i≤s}(1−d_i/n_i) 把删失样本计入风险集；竞争风险下「先出 token」与「先死」是两个竞争终点，用 cause-specific hazard 与 Aalen–Johansen 累积发生率，当 CIF_死(s) 超过 CIF_完成(s) 时杀，而非看完成比例。(4) 校准：分类器给的是分数不是概率。Platt：p=σ(A·f(x)+B)，留出集极大似然拟合；等渗回归非参更灵活但需更多数据且稀疏段过拟合。验收必须用 Brier=mean((p−y)²)（Murphy 分解：可靠性+分辨+不确定）或 ECE=Σ_b w_b|acc(b)−conf(b)|，不能用准确率：准确率固定在 0.5 截断处汇总，而决策阈值在 0.89，一个 97% 准确但对「已死」系统性过度自信的分类器会在错误 posterior 处误杀，期望损失差数倍；Brier 是 proper scoring rule，激励诚实概率。(5) 漂移：选 ADWIN——维护变长窗口 W，当两子窗均值差 |μ̂_L−μ̂_R| ≥ ε_t=sqrt((1/(2m))·ln(4|W|/δ')) 时裁掉旧窗；监控 TTFB 分布、字节速率与判死标签率。重训判据：报警即冻结自动闸门降级为提示模式，累计 ≥300 条新标注（含人工复核）后重训并重跑校准，3 个派活批次内完成降级。


## 三、为什么不用大模型

延迟：分类器特征查表+线性/GBDT 推理 <1ms；1.5B 模型本机 CPU 1~3s，走免费 API 另加 1~5s TTFB。判定器需每通道每 5s 评估一次，5 通道即 60 次/分钟——分类器零负担；小模型每分钟烧 1~3 分钟纯推理，且与被判定通道抢同一份免费额度（自耗）。可解释性：logistic 权重与 GBDT 分裂可逐条审计、可写进 decision-log；LLM 判定带温度随机性、输出无校准概率，出错无法归因。失效模式：分类器坏是软失效（分数漂移，Brier 监控可发现）；LLM 判定器与被判定通道同属一个失效家族——它自己的配额错误会伪装成判定幻觉，判定器与被判定者同时死，故障相关。反转条件：当状态判定需要读语义而非看统计特征（区分「配额错误伪装的空产出」与「真空产出」、识别占位文案）时，特征工程分离不开，语义层小模型就有正当性——这正是 B 的领地：B 的结构部分（剥 JSON 壳）用确定性规则零模型成本，语义部分用小模型。

## 四、路线图与验收门

阶段一（数据基建，2~4 周视派活频次）：改造日志记录删失观测（开始时刻、掐断时刻、掐断原因、父审结论作标签），产出每通道 KM 曲线与 CIF。样本门：每通道 ≥738 条含删失记录（完成+掐断），不足则延长采集，不许提前进阶段二。阶段二（小分类器+校准）：特征=TTFB/字节速率/token 速率/心跳间隔/错误文本正则，logistic 或深度 ≤6 的 GBDT，留出集 Platt 校准。通过判据（时间回测、删失感知指标）：误杀率 ≤2% 且已死召回 ≥95% 且 Brier ≤0.10 且 ECE ≤0.05 → 接进自动闸门；仅达误杀 ≤5% 且召回 ≥90% → 只做提示不自动杀；再低不上线。阶段三（在线监控+影子运行）：ADWIN 监控+影子模式 2 周（只打分不执行）。通过判据：影子期误杀 ≤1/50 次派活，且相对手调阈值总风险 R̂ 下降 ≥30%（≥100 次派活配对比较）；漂移报警→降级→重训闭环至少演练一次成功。C 的 PRD 压缩排最后：只省输入侧 TTFB 的 10~20%，且有截断关键需求的正确性风险。


## 排序与量化理由

A > B > C。A：今天单日 2 误杀+2 漏判 ≈270s 可避免损失，按削减 80% 计约 215s/天，样本在现有日志+父审中持续积累。B：畸形产物触发整轮修复 85s；剥 JSON 壳是确定性规则零成本，剩余语义修复用小模型每次 1~3s；若畸形占失败 30%、其中 70% 可修，按 10 次派活/天估约 130s/天，收益次于 A 且可由 A 触发（判为畸形才调小模型），二者互补。C：只省输入 token 与一小段 TTFB，还引入截断需求风险，排最后。

## 五、脆弱点

1) 若通道间行为分布差异大于通道内差异（4 条 GUI 客户端分布几乎不相交），单池化模型不如四套阈值，只能退回每通道独立模型，而 738 条/通道可能永远凑不齐，方案崩。2) 若标签来自旧阈值的杀活决策本身（循环标注），分类器学到的是旧阈值偏差不是真值；父审覆盖率 <50% 或标签噪声 >3% 时 ε=0.02 不可达，必须先建人工复核标签集。3) 若平台改版不改变可观测特征分布（如伪造心跳流但实际已死），ADWIN 在特征空间看不见漂移，统计判定器整体失效，结论反转偏向语义方案 B。4) 若误杀成本 F 的主导项是配额损耗而非 85s 修复（免费额度中途耗尽），F 被低估 5 倍会把最优阈值从 0.89 推到 ≈0.97，期望等待多出分钟级，损失矩阵须按额度余量动态化。5) 若真实状态不止三态（如「限流但 10 分钟后自愈」是可调度状态），二动作 {等,杀} 与损失矩阵整体作废，需加第三动作「挂起重试」。

## 六、结论

免费额度约束下优先投 A：直接命中实测 270s/天损失、样本持续可得、判定器 <1ms 不耗额度；B 的剥壳规则可顺手先做，语义部分等 A 上线后由其触发；C 收益最小风险最高，暂缓。手调 45s/15s/60s 换成 SPRT/后验阈值后，误杀与漏判的第一性来源（丢弃先验证据+删失偏乐观）均被覆盖。
